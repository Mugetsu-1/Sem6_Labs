# Sem 6 Labs - Repository Overview

This repository contains all the lab assignments and projects from Semester 6. Each folder represents a different course or subject area.

## Directory Structure

- **CompilerLab** - Compiler Design and Construction lab (C++, Flex, Bison)
- **dotnet** - .NET/C# programming assignments and labs
- **SEPrj** - Software Engineering Project: Hospital Doctor Appointment Booking System
- **newastore** - Django-based e-commerce/store application
- **SWE** - Software Engineering diagrams and documentation

## Lab Details

### CompilerLab
Compiler Design and Construction lab covering:
- Lexical analysis with Flex
- Parser construction with Bison
- Syntax analysis (LL(1), SLR, LR(1), LALR(1))
- Semantic analysis, symbol tables, type checking
- Intermediate code generation and optimization
- 8086 assembly code generation

### dotnet
 .NET/C# programming labs covering:
- Unit 1: Basic C# concepts, OOP fundamentals
- Lab 1-10: Various ASP.NET Core topics including MVC, Web API, Razor Pages, Entity Framework, Identity, etc.
- Database setup with SQL Server and Entity Framework Core

### SEPrj
Hospital Doctor Appointment Booking System:
- Full-stack web application for patient-doctor discovery and appointment scheduling
- Features for patients, doctors, and administrators
- JWT authentication, RBAC role-based access control
- PostgreSQL with partial unique indexes for concurrency-safe slot management

### newastore
Django-based e-commerce application:
- Store management system
- User authentication and profile management
- Product catalog and shopping functionality

### SWE
Software Engineering course materials including:
- Diagrams for various systems (Voting System, Payment Workflow, Ticket Booking, etc.)
- Documentation and reports
